Data Science Portfolio Repository:

This folder contains a collection of machine learning and data science projects, demonstrating proficiency across various analytical techniques and modeling approaches.

Technical Scope
This portfolio showcases expertise in the following areas:

Data Preprocessing: Feature Scaling, Normalization, Outlier Treatment, Data Transformation Techniques.

Dimensionality Reduction: Principal Component Analysis (PCA).

Core ML Models: Multiple Linear Regression (MLR), Logistic Regression, Support Vector Machine (SVM), Decision Tree, Random Forest.

Gradient Boosting: XGBoost (XGBM), LightGBM (LGBM).

Unsupervised Learning: Clustering.

Time Series: ARIMA, Recurrent Neural Networks (RNN).

Deep Learning/NLP: Natural Language Processing (NLP), Artificial Neural Networks (ANN),RNN.

Advanced Systems: Recommendation Systems.
